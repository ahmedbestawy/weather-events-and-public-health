# weather-events-and-public-health
Sever weather events have huge impact on public health and economy. In this analysis we will explore the U.S. National Oceanic and Atmospheric Administration’s (NOAA) storm database to discover the impact of different events on economy and number of people lost their life and who suffered injuries.

It is published on Rpubs. Click [Visit RPubs](http://rpubs.com/a7med/1466406) to see the rendered HTML document. 

You can download the "Rmd" file yourself, run the entire analysis and render it to HTML.
